O que é Git e GITHUB ?

Git

O GIT é um sistema de controle de versões que permitem acompanhar as alterações realizamos nos arquivos de um projeto.

Com ele, podemos registrar alterações, recuperar versões anteriores e trabalhar em equipe.

GITHUB.

O GITHUB é uma plataforma de hospedagem de código-fonte e controle de versão usando o GIT.

Ele permite que desenvolvedores colaborem em projetos, compartilhem código e gerenciem versões de forma eficiente.
